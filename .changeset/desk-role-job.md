The agent desk adds the role job (ADR 0021). Run a role in New work, or Run on a report agent in
Agents, runs one report agent from the agent library against a repository path, a GitHub issue, or
your brief, without an issue run. The agent reads and reports; you read the report at the gate and
close the job. Nothing is pushed or filed.
