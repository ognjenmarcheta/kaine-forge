# Environment Setup

Required tools:

- Node.js 22 or newer.
- pnpm 10.29.3 or compatible pnpm 10.
- Docker Desktop or compatible Docker runtime for local Postgres and RustFS storage and optional image builds.
- Rust toolchain for desktop/Tauri work.

Useful environment variables:

- `DATABASE_URL`, `ALLOW_LOCAL_DB_PUSH`
- `BETTER_AUTH_SECRET`
- `BETTER_AUTH_URL`, `WEB_APP_URL`
- `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`
- `VITE_AUTH_SOCIAL_PROVIDERS`, `EXPO_PUBLIC_AUTH_SOCIAL_PROVIDERS`
- `EMAIL_PROVIDER`, `RESEND_API_KEY`, `EMAIL_FROM`
- `AUTH_REQUIRE_EMAIL_VERIFICATION`
- `AUTH_PASSWORD_BREACH_CHECK`
- `TURNSTILE_SECRET_KEY`, `TURNSTILE_ALLOWED_HOSTNAMES`, `VITE_TURNSTILE_SITE_KEY`, `EXPO_PUBLIC_TURNSTILE_SITE_KEY`, `EXPO_PUBLIC_TURNSTILE_BASE_URL`
- `API_HOST`
- `API_PORT`, `WEB_PORT` (per-worktree ports)
- `API_URL`
- `API_CORS_ORIGINS`
- `API_RUN_MIGRATIONS`
- `API_GRAPHQL_MAX_DEPTH`, `API_GRAPHQL_MAX_COMPLEXITY`, `API_GRAPHQL_INTROSPECTION`
- `API_RATE_LIMIT_ENABLED`, `API_RATE_LIMIT_MAX`, `API_RATE_LIMIT_WINDOW_MS`
- `API_TRUST_PROXY`, `API_TRUSTED_PROXY_HOPS`, `API_SHUTDOWN_TIMEOUT_MS`
- `JOBS_RUNNER_ENABLED` (background jobs on pg-boss)
- `AI_TODO_PROVIDER`, `AI_TODO_MODEL`, `AI_ASSISTANT_PROVIDER`, `AI_ASSISTANT_MODEL`, `OPENAI_API_KEY`, `DEEPSEEK_API_KEY`
- `OBSERVABILITY_ENABLED`, `SENTRY_DSN`, `OTEL_EXPORTER_OTLP_ENDPOINT`
- `LOG_LEVEL`
- `VITE_API_URL`
- `VITE_API_PROXY_TARGET`
- `VITE_GRAPHQL_URL`
- `EXPO_PUBLIC_API_URL`
- `EXPO_PUBLIC_GRAPHQL_URL`
- `S3_ENDPOINT`, `S3_REGION`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `S3_BUCKET`, `S3_FORCE_PATH_STYLE`, `S3_PRESIGNED_URL_EXPIRY`, `S3_UPLOAD_URL_EXPIRY`, `S3_DOWNLOAD_URL_EXPIRY`
- `S3_PUBLIC_BUCKET`, `S3_PUBLIC_BASE_URL` (Public Assets)
- `STORAGE_SWEEP_ENABLED`, `STORAGE_SWEEP_INTERVAL_MS`, `HOUSEKEEPING_ENABLED`, `HOUSEKEEPING_INTERVAL_MS`
- `RETENTION_*_DAYS` retention windows, `DATA_EXPORT_ARCHIVE_DAYS`
- `FEATURE_FLAG_<KEY>` process-wide feature flag overrides
- `BILLING_PROVIDER` (`none`, `stripe`, `paddle`), `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `PADDLE_API_KEY`, `PADDLE_WEBHOOK_SECRET`, `PADDLE_CLIENT_TOKEN`, `PADDLE_ENVIRONMENT`, `BILLING_PRICE_*`

Start from `.env.example` and never commit real secrets.
