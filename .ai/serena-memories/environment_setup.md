# Environment Setup

Required tools:

- Node.js 22 or newer.
- pnpm 10.29.3 or compatible pnpm 10.
- Docker Desktop or compatible Docker runtime for local Postgres/MinIO and optional image builds.
- Rust toolchain for desktop/Tauri work.

Useful environment variables:

- `DATABASE_URL`
- `BETTER_AUTH_SECRET`
- `BETTER_AUTH_URL`
- `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`
- `VITE_AUTH_SOCIAL_PROVIDERS`, `EXPO_PUBLIC_AUTH_SOCIAL_PROVIDERS`
- `EMAIL_PROVIDER`
- `AUTH_REQUIRE_EMAIL_VERIFICATION`
- `API_HOST`
- `API_PORT`
- `API_URL`
- `API_CORS_ORIGINS`
- `API_RUN_MIGRATIONS`
- `API_GRAPHQL_MAX_DEPTH`
- `API_RATE_LIMIT_ENABLED`, `API_RATE_LIMIT_MAX`, `API_RATE_LIMIT_WINDOW_MS`
- `API_TRUST_PROXY`
- `LOG_LEVEL`
- `VITE_API_URL`
- `VITE_API_PROXY_TARGET`
- `VITE_GRAPHQL_URL`
- `VITE_ORGANIZATIONS_VISIBLE`
- `EXPO_PUBLIC_API_URL`
- `EXPO_PUBLIC_GRAPHQL_URL`
- `EXPO_PUBLIC_ORGANIZATIONS_VISIBLE`
- `S3_ENDPOINT`, `S3_REGION`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `S3_BUCKET`, `S3_FORCE_PATH_STYLE`, `S3_PRESIGNED_URL_EXPIRY`

Start from `.env.example` and never commit real secrets.
