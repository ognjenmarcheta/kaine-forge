# Core

Entry point for Kaine Forge memories. These memories are read-only; edit `.ai/serena-memories/` and run `pnpm ai:install`.

- `mem:project_overview`: read first in a new area; apps, packages, and template intent.
- `mem:architecture_patterns`: read before adding files or moving code; feature folders and package boundaries.
- `mem:domain_overview`: read before choosing where a change belongs (web, mobile, desktop, API, shared package).
- `mem:coding_standards`: read before writing or changing code.
- `mem:environment_setup`: read when a tool, runtime, or local service is missing.
- `mem:suggested_commands`: read before running checks, generators, or database commands.
- `mem:quality_expectations`: read before writing tests or preparing a PR.
- `mem:task_completion_checklist`: read before reporting work as done.
