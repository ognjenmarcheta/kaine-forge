# Agent Instructions

## Primary Monorepo Rules

- Read `MONOREPO_GUIDE.md` before generating, modifying, or reviewing code.
- Treat `MONOREPO_GUIDE.md` as the authoritative source for architecture decisions, naming patterns, conventions, and constraints.

## UI and Design Rules

- For UI, styling, theming, tokens, and component behavior, follow `DESIGN_SYSTEM.md`.
- Use `DESIGN_SYSTEM.md` alongside `MONOREPO_GUIDE.md`, not as a replacement.

## Priority and Conflict Resolution

- Apply monorepo-wide engineering constraints from `MONOREPO_GUIDE.md` first.
- For visual/design-specific decisions, apply `DESIGN_SYSTEM.md`.
